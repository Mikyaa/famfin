# Семейный бюджет в Telegram

Бот + Mini App + сайт для учёта общих и личных расходов. Работает на обычном PHP-хостинге без root, Node.js и фоновых процессов. Нужны PHP 8.1+, MySQL (или SQLite для локального теста) и расширения `pdo_mysql`/`pdo_sqlite`, `curl`, `mbstring`.

## Модель бюджета

**Общий котёл.** Пополнения и расходы учитываются по человеку, но остаток общий:
- `Общий остаток = Σ пополнения − Σ расходы` за всё время
- `Личный остаток X = X.пополнения − X.расходы` (может быть отрицательным — значит человек взял из общего больше, чем вложил)
- Сумма личных остатков всегда равна общему

**Категории делятся на две группы:**
- **Обязательные (fixed):** Продукты, Дом, Транспорт, Здоровье, Дети, Подписки, Кредиты
- **Переменные (variable):** Кафе и рестораны, Покупки, Путешествия, Развлечения, Другое

Маппинг в `config.php → category_groups`. Свои категории можно добавлять прямо в форме — они попадают в выбранную группу и сохраняются в БД, так что старая аналитика не ломается при переименовании.

## Разделы сайта

### Основное
Актуальное состояние на сегодня, без выбора периода:
- Общий бюджет: остаток, всего внесено, всего потрачено
- Карточки Я / Жена: личный остаток, доля в общем, внесено/потрачено
- Текущий месяц: расходы, обязательные, переменные
- Последние 10 операций
- Форма добавления записи

### Отчёты
Полный анализ за выбранный период:
- Пресеты: Сегодня, Неделя, Месяц, Год, Всё время
- Ручной диапазон: две даты + «Применить»
- Сводка: расходы, пополнения, изменение, число операций
- Сравнение с предыдущим периодом той же длины (дельта % по расходам, обязательным, переменным)
- Обязательные vs переменные с долями
- Остатки на конец периода (общий + личные)
- Участники: кто сколько потратил/пополнил, топ-3 категории каждого
- Категории: топ-N с фильтром (Все / Обязательные / Переменные)
- График расходов по дням (до 180 дней)
- Полная лента операций с пагинацией (50 на страницу)
- Экспорт CSV по выбранному периоду

### Лимиты
Настраиваются в профиле (кнопка с буквой в правом верхнем углу):
- **семейные** — считаются по тратам обоих, видны и приходят обоим; **личные** («Только мои») — только по своим тратам, видит и получает уведомления только владелец;
- **на месяц** или **на неделю** (с понедельника), на любую категорию, включая свои, и общий лимит «Все расходы»;
- **не блокируют** запись — трату можно сохранить и сверх лимита, он просто уйдёт в минус;
- **перенос остатка** (переключатель в профиле, по умолчанию включён): неистраченное за прошлый период прибавляется к лимиту, перерасход вычитается. Учитывается только предыдущий период, без накопления, и только если лимит уже существовал в нём;
- порог предупреждения 10/20/30% остатка;
- бот пишет один раз, когда остаток опустился ниже порога, и один раз, когда лимит исчерпан или превышен. Изменение лимита или настроек снова включает уведомления. Об изменении семейных лимитов бот сообщает второму участнику;
- на «Основном» — прогресс по каждому лимиту (тап открывает детализацию; для личного — только ваши траты), в форме добавления — подсказка «останется / будет превышен на»;
- команда бота `/limits`.

В `local_test_mode` уведомления не отправляются в Telegram, а пишутся в лог PHP.

### Запись трат сообщением боту
Боту можно просто написать: «кафе 5000», «12 300 продукты магнум», «вчера такси 1.8к», «28.09 аптека 4500», «+350 000 зарплата». Сумма, дата и категория определяются автоматически (словарь ключевых слов в `features.php → CATEGORY_KEYWORDS` плюс ваши категории). Если категорию не угадать, бот предложит кнопки. Под каждой записью — «Категория» и «Отменить».

### Редактирование и переводы
Нажатие на операцию открывает её для правки: сумма, категория, дата, комментарий, кто платил. В форме добавления есть третий вид — «Перевод» между вами: личные остатки меняются, общий нет.

### Цели
Копилки с суммой и сроком: показывают, сколько откладывать в месяц. Отложенное уходит из остатка того, кто отложил, и видно в «В копилках». Закрытая цель возвращает деньги в бюджет.

### Регулярные платежи и прогноз
Профиль → «Регулярные платежи»: сумма, категория, день месяца, кто платит. В этот день бот присылает напоминание с кнопками «Оплачено» и «Пропустить». На главной показаны платежи месяца и прогноз трат к концу месяца (после 5-го числа): текущий темп повседневных трат плюс ещё не оплаченные платежи.

### Поиск, импорт, тема
- Поиск по всем операциям (лупа у «Последних операций»): комментарий, категория, человек или сумма.
- Профиль → «Импорт выписки Kaspi»: PDF разбирается в браузере (pdf.js), покупки отмечаются сразу, переводы и пополнения — на ваше усмотрение, уже записанные операции распознаются как дубли.
- Тема: авто (по Telegram или системе), светлая, тёмная. В Telegram используются нативные кнопки «Сохранить» и «Назад» и вибрация.

### Резервные копии и итоги месяца
`backup.php` (cron ежедневно) делает снимок базы, хранит 30 дней в `backups/` рядом с базой и тихо отправляет файл в `backup_chat_id`. Команда `/backup` присылает копию сразу. `daily.php` (cron каждое утро) рассылает напоминания о платежах, а 1-го числа — итоги прошлого месяца обоим.

```
30 3 * * * php backup.php
0 9 * * * php daily.php
```

### Еженедельный отчёт в канал
По понедельникам бот публикует в `report_chat_id` итоги прошлой недели (пн–вс): картинку с анализом (потрачено, общий остаток, траты по дням, топ категорий, кто сколько потратил, семейные лимиты) и короткую подпись. Бот должен быть администратором канала. Картинка рисуется через GD шрифтом Inter из `fonts/`.

```
php weekly_report.php                       # отправить за прошлую неделю (повтор за ту же неделю пропускается)
php weekly_report.php --out=week.png        # только нарисовать
php weekly_report.php --week=2026-09-28 --chat=-100123 --force
```

Cron: `0 9 * * 1 /usr/bin/php /path/to/weekly_report.php >> /path/to/weekly.log 2>&1`.

### Закреплённая карточка остатка в канале
В `widget_chat_id` (по умолчанию тот же `report_chat_id`) бот один раз публикует картинку-карточку общего остатка: общий и личные остатки, внесено и потрачено всего, траты за месяц, общий месячный лимит. Затем закрепляет её без уведомления. После каждого добавления или удаления операции карточка заменяется в том же сообщении, поэтому закреп остаётся на месте. Боту нужны права администратора: публикация, редактирование и закрепление сообщений.

```
php widget_update.php            # cron раз в минуту: обновить, если баланс менялся
php widget_update.php --force    # обновить сейчас
php widget_update.php --out=card.png
```

## Локальный тестовый режим

В локальном `config.php` включён `local_test_mode` на SQLite. Из папки проекта:

```
php -S 127.0.0.1:8000 router.php
```

Откройте `http://127.0.0.1:8000`. При первом обращении создаётся `storage/budget.sqlite` с демо-операциями и автоматически применяется миграция `category_group`. На странице входа появятся кнопки «Войти как Я» / «Войти как Жена», а в шапке — переключатель участника. Тестовый обход Telegram-авторизации принимается только с `127.0.0.1`/`::1`.

Перед размещением на хостинге скопируйте `config.example.php` в `config.php`, установите `local_test_mode` в `false`, задайте MySQL и новый токен бота.

## Установка на хостинг

1. Создайте MySQL базу и импортируйте `schema.mysql.sql` через phpMyAdmin. Если таблица `transactions` уже существует без `category_group`, выполните `ALTER TABLE` из комментария в конце файла — либо просто откройте сайт один раз, миграция применится автоматически.
2. Загрузите файлы проекта в web-root. Скопируйте `config.example.php` в `config.php` и заполните: `bot_token`, `webhook_secret` (случайная строка), доступ к БД, `app_url` (HTTPS адрес сайта). Не публикуйте `config.php`.
3. В BotFather:
   - настройте Mini App URL на `https://ВАШ-ДОМЕН/`;
   - включите Login Widget для того же бота (команда `/setdomain`);
   - установите команды `/start`, `/balance`, `/week`, `/month`, `/help`.
4. Настройте webhook на `https://ВАШ-ДОМЕН/webhook.php`, передав в `setWebhook` тот же `webhook_secret` как `secret_token`.
5. Откройте бота и нажмите Start с обоих аккаунтов. Кнопка «Открыть бюджет» запускает Mini App. Прямой заход на сайт показывает Telegram Login Widget.

## Команды бота

- `/start` — приветствие и кнопка Mini App.
- `/balance` — текущие остатки (общий + личные).
- `/week` — сводка за текущую неделю + остатки.
- `/month` — сводка за текущий месяц + остатки.
- `/limits` — семейные и ваши личные лимиты: потрачено, остаток или превышение.
- `/help` — справка.

Команды понимают суффикс `@botname` в группах.

## Локальный polling (без хостинга)

Если нужно гонять бота локально без webhook:

```
php polling.php
```

Скрипт сам снимет webhook (не теряя очередь), зарегистрирует команды и будет слушать обновления. Работает только из CLI — при обращении по HTTP возвращает 403.

## Безопасность

**Файл SQLite держите вне web-root.** На nginx + Apache (FastPanel и т.п.) nginx отдаёт статические файлы сам и `.htaccess` для них не применяется — `storage/budget.sqlite` внутри сайта скачивается по прямой ссылке. Укажите в `config.php` путь вида `/var/www/<user>/data/famfin-data/budget.sqlite`. `local_test_mode` на хостинге — только `false`.

Сервер добавляет заголовки CSP, `nosniff`, `Referrer-Policy`; сессионная cookie — `HttpOnly`, `SameSite=Lax`, `Secure` при HTTPS. Вход по коду ограничен 5 попытками с IP в минуту, а после 30 неудачных попыток со всех IP все активные коды сгорают. Экспорт CSV экранирует формулы (`=`, `+`, `-`, `@`).

`.htaccess` и `router.php` блокируют прямой доступ к `config.php`, `lib.php`, `polling.php`, `router.php`, `schema.mysql.sql`, `README.md`, `.gitignore`, `.env*`, `storage/`, `src/`. Токен, который засветился в переписке, обязательно перевыпустите в BotFather (`/revoke`) перед запуском.
